# Licensing notes

**Not legal advice.** This records what the packages declare and how SEM Lab is structured.

## SEM Lab's licence

SEM Lab — the web app, the TypeScript and Python engines, the R verification code, the
exported-script templates, the notebooks, the learning content and the synthetic datasets — is
released under the **MIT License** (`LICENSE`). Third-party components keep their own licences:
`THIRD_PARTY_NOTICES.md` (generated by `scripts/third-party-notices.mjs`, checked in CI). The
single-file Python engine (`packages/python-engine/dist/semlab_bundle.py`), which travels
alone in exported ZIPs and inside each notebook, embeds the full MIT notice.

Everything bundled into the web app is under a permissive licence (MIT, ISC, BSD, Apache-2.0),
except elkjs, used unmodified under EPL-2.0 (file-level copyleft that does not extend to SEM
Studio), and the OFL-1.1 fonts. The notices script fails if a dependency with any other licence
appears.

## Independent implementations

The engines reproduce R's behaviour without containing R or package code:

- Estimators (PLS-PM, PLSc, assessment criteria, IPMA, ML/MLR/FIML, fit indices) are written from
  the published methods and the packages' documentation, then verified against cSEM / lavaan
  output (`packages/fixtures/reference-results`). No cSEM, lavaan, seminr, plspm or semopy code
  is included.
- The R-compatible random numbers use MT19937 (Matsumoto & Nishimura 1998; reference
  implementation under a BSD-style licence) with R's documented seeding and rejection sampling,
  so exported R scripts draw the same bootstrap rows; this is interoperability with R's output.
- Distribution functions use textbook methods (Lanczos log-gamma, continued fractions, Poisson
  mixture for the noncentral χ²); the RMSEA interval root finder is Brent's (1973) algorithm, in
  the form R's `uniroot()` uses, so that lavaan's interval limits are reproduced.

## Structure relevant to copyleft

- The application is a static web app. Its estimation engine (`packages/engine`) is SEM
  Studio's own TypeScript code; no GPL package is bundled or executed in the browser.
- GPL R packages (cSEM, seminr, lavaan) and plspm are used only by the verification oracle
  (`services/r-engine`, `services/python-spike`) on developer machines and in CI, and by
  scripts that users export and run themselves. Exported scripts call those packages but
  contain none of their code.
- SEM Lab's Python engine (`packages/python-engine`, numpy/scipy) is its own code, shipped
  with Python exports.
- elkjs under EPL-2.0: keep its notice in the bundle's third-party notices and point to its
  source; SEM Lab does not modify elkjs.

## Data

- **ACSI 2015** (`packages/fixtures/third-party/smartpls-samples/acsi-2015/`): CC BY 4.0, with
  the attribution shipped in the app, the example and `THIRD_PARTY_NOTICES.md`. Not MIT.
- **Five further SmartPLS sample datasets** (TAM, UTAUT, OI, Concise Guide, HBAT): no
  redistribution terms could be verified (`PROVENANCE.md`). They are git-ignored, kept on the
  owner's machine only, and were removed from the repository history before it was published;
  tests that use them skip when they are absent.
- **Synthetic datasets** (`packages/fixtures/synthetic/`): generated by this repository; MIT.
- The source folder `TEMP/` (SmartPLS project files) is git-ignored and was never committed.

## SmartPLS
