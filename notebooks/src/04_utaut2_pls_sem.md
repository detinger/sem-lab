**Attribution.** The model is inspired by the extended unified theory of acceptance and use of

reproduce any published study, and the model is a simplified teaching version (no price value
construct and no moderators).

### Learning objectives

After this notebook you can

1. estimate an eight-construct adoption model with six correlated predictors of intention;
2. formulate and test nine directional hypotheses with bootstrap confidence intervals, and
   report them in a hypothesis table;
3. interpret a **non-significant** path correctly (and explain why a sizeable correlation can go
   together with a negligible unique effect);
4. check collinearity among predictors (VIF) and effect sizes (f²);
5. separate direct and indirect effects on use behaviour.

### Theory and *illustrative* hypotheses

UTAUT2 explains behavioural intention (**BI**) with performance expectancy (**PE**), effort
expectancy (**EE**), social influence (**SI**), facilitating conditions (**FC**), hedonic motivation
(**HM**) and habit (**HT**); use behaviour (**USE**) depends on intention, facilitating conditions
and habit.

| | Hypothesis (illustrative) | | Hypothesis (illustrative) |
|---|---|---|---|
| H1 | PE → BI (+) | H6 | HT → BI (+) |
| H2 | EE → BI (+) | H7 | FC → USE (+) |
| H3 | SI → BI (+) | H8 | HT → USE (+) |
| H4 | FC → BI (+) | H9 | BI → USE (+) |
| H5 | HM → BI (+) | | |

Synthetic, cross-sectional data cannot establish that any of these influences exist; the
arrows express the model's assumptions.

## 7. Structural model: testing the hypotheses

%% code
paths = rep["paths"]
hyp = pd.DataFrame({
    "H": [f"H{k}" for k in range(1, 10)],
    "path": [f"PE {ARROW} BI", f"EE {ARROW} BI", f"SI {ARROW} BI", f"FC {ARROW} BI", f"HM {ARROW} BI",
             f"HT {ARROW} BI", f"FC {ARROW} USE", f"HT {ARROW} USE", f"BI {ARROW} USE"],
})
hyp = hyp.merge(paths, on="path", how="left")
hyp["decision"] = ["supported" if s else "not supported" for s in hyp["significant (95% CI excludes 0)"]]
hyp_table = hyp[["H", "path", "est", "se", "statistic", "pValue", "ciLower", "ciUpper", "decision"]]
show(hyp_table, 4)
FIGURES["paths.png"] = coefficient_plot(hyp.assign(label=hyp["H"] + "  " + hyp["path"]), label_col="label")
plt.show()

%% markdown
**Interpretation.** Eight of the nine hypotheses are supported in this sample: their 95%
intervals exclude zero. Performance expectancy and habit are the strongest predictors of
intention, followed by hedonic motivation and facilitating conditions; social influence is
small but its interval excludes zero. **H2 (EE → BI) is not supported**: the estimate is close to
zero (about 0.03) and its interval clearly includes zero (p ≈ 0.5).

How to report a non-significant path:

- Say that the data do **not provide evidence** for H2 — not that "EE has no effect". A
  non-significant result is compatible with a zero effect *and* with small positive or
  negative effects; the interval shows which values remain plausible (roughly −0.05 to
  +0.11 here).
- Do not delete the path to "improve" the model: it was hypothesised, so it is reported.
- Remember the population value is 0.03. The test did what it should: with N = 450 such a small
  effect cannot be distinguished from zero.

### Correlation is not the same as a unique effect

%% code
frames = semstudio.to_dataframes(result, model)
corr = frames["matrix:construct-correlations"].set_index("")
corr.index.name = None
corr = corr.astype(float)
print("Construct correlations with BI:")
show(corr["BI"].drop("BI").to_frame("r with BI"))
print("Construct correlations of EE with the other predictors:")
show(corr.loc["EE", ["PE", "SI", "FC", "HM", "HT"]].to_frame("r with EE"))

%% markdown
**Interpretation.** EE correlates clearly with BI (about 0.35), yet its path coefficient is near
zero. The path is a *partial* coefficient: it measures EE's association with BI after holding
the other five predictors constant. EE overlaps with PE, FC and HM, so once they are in the
model, little unique information about BI is left in EE. In UTAUT terms, ease of use may matter
through other perceptions, but this model does not test that (there is no EE → PE path).

## 8. Direct and indirect effects on use behaviour

Facilitating conditions and habit affect use directly and through intention. The predictors
of BI without a direct path to USE (PE, EE, SI, HM) can affect use only indirectly.

%% code
eff = rep["effects"]
use_eff = eff[eff["to"] == "USE"]
table = use_eff.pivot_table(index="from", columns="effect", values="est", sort=False)
direct = paths[paths["to"] == "USE"].set_index("from")["est"]
table.insert(0, "direct", direct)
show(table)
show(use_eff[use_eff["effect"] == "specific indirect"][["route", "est", "ciLower", "ciUpper",
                                                        "significant (95% CI excludes 0)"]], 4)

%% markdown
**Interpretation.** Habit has the largest total effect on use: a direct effect plus an indirect
effect through intention. Performance expectancy affects use only through intention. EE's
indirect effect on use (EE → BI → USE) is near zero and its interval includes zero, which follows
from the non-significant first link. A significant indirect effect requires evidence for the
product of both links, not just for one of them.

### What about moderation?

UTAUT2 hypothesises that age, gender and experience moderate several paths. SEM Studio's
engine does not offer interaction terms or multigroup analysis in this version (the app states
such limits openly instead of approximating them), and this synthetic dataset has no
moderator variables. Moderation is therefore left out here; treat any moderation analysis as a
separate, carefully specified study (e.g. a two-stage interaction term or a multigroup
analysis with measurement invariance checks).

## 10. Summary and questions

- The eight reflective constructs meet the reliability, AVE and HTMT guidelines.
